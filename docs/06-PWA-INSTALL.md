# PWA 설치 & 사용 가이드 (아이폰)

리치시그널은 **PWA(Progressive Web App)** 입니다. 앱스토어·Xcode·케이블·서명 만료 없이,
Safari에서 홈 화면에 추가하면 네이티브 앱처럼 씁니다.

## 준비물

- 아이폰 (iOS 16.4 이상 — 웹 푸시 사용 시 필수)
- 배포 주소: `https://richman-production.up.railway.app`
- API 키 (Railway `richman` 서비스의 `API_KEY` 값)

## 설치 (3단계)

1. **Safari**로 배포 주소 접속 (Chrome 아님 — iOS 홈 화면 PWA는 Safari 기준)
2. 하단 공유 버튼 → **"홈 화면에 추가"** → 추가
3. 홈 화면에 생긴 **리치시그널 아이콘으로 실행**

## 최초 설정

앱을 처음 열면 데이터가 안 보입니다. **설정 탭**에서:

1. **API 키** 입력 → 저장 (서버 URL은 비워두면 = 접속한 사이트)
2. **연결 테스트**로 `정상 ✓` 확인
3. **대시보드 탭**에 신호/국면/섹터가 뜨면 완료

## 웹 푸시 알림 켜기

> iOS는 **홈 화면에 추가(standalone) + 홈 아이콘으로 실행**한 상태에서만 웹 푸시가 됩니다.
> Safari 탭에서 연 상태로는 토글이 비활성입니다.

1. 홈 화면 아이콘으로 앱 실행 → **설정 탭**
2. **"푸시 알림 받기"** 켜기 → iOS 권한 요청에 **허용**
3. **"테스트 푸시 보내기"** 로 잠금화면 알림 확인

이후 신호가 바뀌면 앱이 닫혀 있어도 알림이 옵니다:
- **현금보유 전환** → 즉시
- 그 외(보유 전환·국면 변경) → 배치(크론) 실행 시 묶어서

## 업데이트

프론트 코드를 재배포하면 다음 실행 때 자동 반영됩니다(서비스워커 네트워크 우선).
반영이 안 되면 앱을 완전히 종료 후 다시 여세요.

## 문제 해결

- **데이터가 안 뜸 / "키 확인 필요"**: 설정에서 API 키 재확인 (`railway variables -s richman --kv | grep API_KEY`)
- **푸시 토글이 비활성 / "키 입력 필요"**: 먼저 API 키 저장. "서버 미설정"이면 Railway에 `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` 설정 필요
- **푸시 토글이 안 켜짐**: 홈 화면에 추가한 아이콘으로 실행했는지 확인 (Safari 탭에서는 불가)
